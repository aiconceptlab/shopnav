The cover is labelled AI concept artwork. Slides 02/04 show genuine screenshots from the tested app. These screenshots were captured in the isolated browser scenario after relocating M8 bolts from A1 to B2; the fresh seed starts it at A1. The source layout renderer uses those supplied screenshots, so reproducing the carousel does not require credentials or model access: `npm run instagram`.

This LAB is a deterministic retail navigation experiment. Do not describe it as AI routing, live positioning, automatic shelf detection, real-time inventory, guaranteed optimal tours or proven reduced staff workload. Those are not implemented or established outcomes.
